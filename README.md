# 🎉 YouCode Events

A web development project focused on events, built with **HTML and CSS**.

## 📌 About the Project

**YouCode Events** is a front-end web project developed to practice and apply web development skills. The repository organizes the HTML pages, CSS stylesheets, and visual assets used by the website.

## 🛠️ Technologies Used

- **HTML5** — Structure and content of web pages.
- **CSS3** — Styling, layout, and visual design.
- **Git & GitHub** — Version control and project collaboration.

## 📂 Project Structure

```text
youcode_events/
├── assets/     # Images and other visual resources
├── css/        # Stylesheets
├── html/       # HTML pages
└── README.md   # Project documentation
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/boukrimbrahim2007/youcode_events.git
```

### 2. Navigate to the project directory

```bash
cd youcode_events
```

### 3. Run the project

Open the main HTML file inside the `html/` directory in your web browser.

For development, you can open the project folder in Visual Studio Code and use the Live Server extension.

## 🎯 Project Objectives

- Practice HTML5 and CSS3.
- Build and organize web pages.
- Improve front-end development skills.
- Learn to structure and manage a project using Git and GitHub.
